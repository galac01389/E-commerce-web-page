## 🛒 E-commerce Website

This is a e-commerce website built to simulate an online shopping experience. It features product listings, a shopping cart, checkout process, and responsive user interface — providing a realistic and seamless browsing experience.

### 🔧 Features

- User-friendly interface with responsive design
- Product listings with images, pricing, and filtering options
- Add-to-cart and quantity 
- Checkout flow with form validation.

### 🚀 Technologies Used

- HTML5 / CSS3
